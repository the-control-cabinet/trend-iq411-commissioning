# 02 Commissioning procedure

[← Back to README](../README.md)

1. **Pre-power checks:** wiring to the drawing; mains segregation; terminals torqued; insulation and continuity checks on the 24 V side.
2. **Power up:** status LEDs; set the address; connect SET.
3. **Point-to-point:** each input and output against the I/O schedule (simulate with a calibrator or resistor box; force outputs).
4. **Strategy download:** check against the written sequence.
5. **Functional tests:** reuse the rig test record (duty/standby, interlocks, PID).
6. **Handover record:** I/O schedule, strategy printout, test results.
